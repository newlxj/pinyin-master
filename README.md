
这就是一个练拼音的，自己可以导入自己的字库内容进行练习，有打字和游戏两种练习模式，打字模式可以自己设置速度和错误率，游戏模式可以自己设置游戏时间和游戏难度。

对你有用给个赞，谢谢！

可以直接下载打包好的或者自己编译

1. Install dependencies:
   `npm install`
2. Run or build the app:
   `npm run dev`  or  `npm run build`
3. go build -o pinyin
